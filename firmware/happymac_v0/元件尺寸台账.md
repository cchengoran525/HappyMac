## 打印配合公差（实测标定）

- **公差条实测：0.10mm** → 全部榫卯动配合（滑插槽/卡扣/檐槽）按 **基准 + 0.10mm** 设计；
- 销钉类静配合：按 **-0.05mm 过盈**试探（打印销 Ø2.95 配 Ø3.0 孔起步）；
- 后续所有间隙数字都以 0.10 为基准，不再用通用估算值。

## 由实测尺寸触发的设计更新

1. **电池 90×60** → L3 层板扩为 **130×80**（电池 90 + 充电模块 28 + 隔热区 12）；占位值 90×70 作废。
2. **LD2450 是 40×15 横条** → 前脸板横向布置正合适；2mm PLA 直穿或格栅开窗，打印后实测灵敏度。
3. **OLED 四角 M3 安装孔** → 前脸板直接螺丝固定 OLED（无需胶/卡扣），窗口按活动区 29.42×14.7 + 1mm 余量切割。
4. **稳压模块 EN/PS 引脚** → 省电架构新选项：PS 短接 = 稳压级待机 <100µA；EN 可做未来"全系统断电"的固件控制点（当前雷达断电仍由 F5305S 承担）。
5. **充电+保护二合一 + 电池自带保护板 = 双重保护确认**（过放 2.5V / 过流 3A / 充电截止 4.2V）——安全清单闭环 ✓。

# HappyMac v0 接线清单

> 整机 = 电池 4000mAh → 充电模块 → 稳压模块(→5V) → ESP32-C3 + F5305S 电源开关 → 双雷达 + OLED + PIR
> 引脚定义与固件 `happymac_v0.ino` 顶部 `#define` 一一对应，改脚位记得两边同步。

## 电源树

```
电池 3.7V(红+黑，第三线 NTC 备用)
  └─► 充电模块 BAT±（永远直连，充电回路不经过任何开关）
        USB 5V ──► 充电模块 IN（充电时插）
        充电 OUT± ──► [可选：全局拨动开关 ≥1A] ──► 稳压模块 IN
                      稳压模块 OUT(5V) ──┬─► ESP32 5V 脚（板载 LDO → 3.3V）
                                          └─► F5305S 模块 IN+/IN-
                                               F5305S OUT+ ──┬─► LD2450 VCC
                                                              └─► LD2410 VCC   ← 被控轨
ESP32 3V3 脚（不受控）──► OLED VCC + PIR VCC
全板 GND 汇共地（ESP32 GND / 模块 GND / 两雷达 GND / OLED GND / PIR GND / F5305S IN-）
```

## 信号线

| 从 | 到 | 线 | 说明 |
|---|---|---|---|
| LD2450 TX | ESP32 **GPIO20** | UART | 雷达数据进（256000 波特） |
| ESP32 **GPIO21** | LD2450 RX | UART | 断电时固件设为高阻（防反灌） |
| LD2410 TX | ESP32 **GPIO4** | UART | |
| ESP32 **GPIO3** | LD2410 RX | UART | 断电时固件设为高阻（防反灌） |
| OLED SDA | ESP32 **GPIO8** | I2C | 注意：GPIO8 是启动模式脚，别接反/接错 |
| OLED SCL | ESP32 **GPIO9** | I2C | 同上 |
| PIR OUT | ESP32 **GPIO5** | 数字 | 高电平=有人；**深度睡眠唤醒脚** |
| F5305S SIG | ESP32 **GPIO1** | 控制 | 高=雷达上电；**串 1kΩ 电阻**（防复位干扰烧录） |

## 电源线

| 从 | 到 | 说明 |
|---|---|---|
| 电池红(+)/黑(-) | 充电模块 BAT± | 三线软包的第三根（NTC 10k 热敏）剪短绝缘收纳，或接充电模块 TEMP 做温控充电 |
| USB 5V | 充电模块 IN | 充电输入；关机状态下插 USB 仍可充电 |
| 充电 OUT± | 稳压模块 IN | 中途可串全局拨动开关（≥1A），只断"用电"不断"充电" |
| 稳压 OUT 5V | ESP32 5V 脚 | |
| 稳压 OUT 5V | F5305S IN+ / IN- | 开关模块供电 |
| F5305S OUT+ | LD2450 VCC、LD2410 VCC | 被控轨：两雷达 VCC 并联（固件 90s 无人断电） |
| ESP32 3V3 | OLED VCC | 不受控 3.3V（I2C 电平合规 + 睡眠呼吸暗脸由固件对比度实现） |
| ESP32 3V3（或 5V） | PIR VCC | 看所用 PIR 模块的宽压范围 |

## 固件引脚对照（.ino 顶部 #define）

| 宏 | GPIO | 方向 | 用途 |
|---|---|---|---|
| PIN_SDA | 8 | I2C | OLED 数据（启动模式脚，接线固定后勿动） |
| PIN_SCL | 9 | I2C | OLED 时钟（同上） |
| PIN_IR | 5 | 输入 | PIR，高=有人；深度睡眠唤醒源 |
| PIN_2410_RX | 4 | 输入 | LD2410 数据进 |
| PIN_2410_TX | 3 | 输出 | LD2410 指令出（断电时设高阻） |
| PIN_2450_RX | 20 | 输入 | LD2450 数据进 |
| PIN_2450_TX | 21 | 输出 | LD2450 指令出（断电时设高阻） |
| PIN_RADAR_PWR | 1 | 输出 | 雷达电源开关，高=上电（串 1k 到模块 SIG） |

## 串口 / 调试

- USB CDC 115200：`STATE/ML/POS/RADAR/ANIM/DIAG` 日志；`!CAL` 重校准、`!DEBUG` 切调试文字层、`!FLIP` 翻转雷达左右、`!PWR` 查电源状态
- 深度省电时间线（可调宏）：入睡 90s 断雷达（`RADAR_OFF_AFTER_MS`）→ +2min 屏幕全黑（`SCREEN_OFF_AFTER_MS`）→ +30min 深度睡眠（`DEEP_SLEEP_AFTER_MS`，PIR 高电平唤醒=重启）

## 安全与布局要点

- 电池↔充电模块之间不放开关（充电回路常通）；全局硬开关放充电 OUT 之后、稳压之前
- 充电模块是全机最热件（快充 0.8~1.6W）：离电池 ≥25mm + 隔板，热源区开散热孔
- 雷达不直接贴 PLA 壳（留 2~3mm 空气隙，PLA 60°C 软化）；PIR 探头背对机内热源、离充电模块 ≥20mm（防热气流误触发）
- F5305S 模块 IN/OUT 不可接反（反接 = 体内二极管常通，开关失效）

# HappyMac 雷达信号表征实验报告

**日期**: 2026-08-13
**实验者**: Chen Mingyuan
**硬件**: ESP32-C3 SuperMini + HLK-LD2450 (1T2R FMCW) + HLK-LD2410C + ESP32-S3-EYE 摄像头
**软件**: collect_session.py v2 (墙钟时间戳对齐), analyze_session.py, analyze_vision.py (MediaPipe Face Landmarker), analyze_depth.py (MiDaS_small)

---

## 1. 实验目的

系统性表征两个低成本 24GHz 毫米波雷达在**桌面尺度**（0.6-1.2m）下对坐姿人体的感知能力边界，回答三个问题：

1. LD2450 的 X/Y 坐标是否反映真实人体位置？
2. LD2410C 的能量通道（Em/Es）携带什么信息？
3. 哪些信号可用于后续 TinyML 行为分类？

## 2. 实验设计

### 2.1 数据采集协议

每 session 包含 10 个阶段（9 个有效 + 1 个被弃用的自由段）：

| 阶段 | 时长 | 行为 |
|------|------|------|
| still_30s | 30s | 静止坐姿 |
| slow_sweep | 20s | 缓慢连续左右摆动 |
| quick_points | 20s | 快速定点左右移动 |
| ellipse | 20s | 上半身椭圆运动 |
| fwd_back | 20s | 前倾/后靠 |
| head_only | 20s | 身体静止，仅转头 |
| natural_typing | 45s | 自然打字 |
| natural_reach | 20s | 伸手取物 |
| stand_sit | 20s | 站起/坐下 |

### 2.2 关键实验控制

- **雷达预热**：每次 session 前雷达静置 ≥3 分钟（冷启动漂移期已提前识别并排除）
- **时间戳对齐**：雷达串口与摄像头 MJPEG 流均以采集计算机的墙钟（`time.time()`）打戳，配对窗口 150ms。延迟扫描确认无残留系统偏移（0ms 时相关性最优）
- **重复性**：完整 protocol 重复 3 次（20260813_160414 / 165801 / 170609）
- **排除项**：`free_5min` 自由段因被试未及时终止被截断，全部分析中排除

### 2.3 验证基准

- **横向位置基准**：MediaPipe Face Landmarker（468 关键点）提取脸部中心 `head_x`（归一化 -0.5~+0.5）
- **距离基准**：MiDaS_small 单目深度估计（intel-isl/MiDaS，PyTorch Hub），取脸部中心 11×11 邻域中位数；MiDaS 输出"越近值越大"，雷达 Y"越近值越小"，故**预期负相关**

## 3. 结果

### 3.1 LD2450 X 轴：横向位置追踪（弱但可重复）

MediaPipe 脸部横向位置与雷达 X 的 Pearson 相关：

| Session | r(X) | 对齐对数 |
|---------|------|---------|
| 160414 | +0.207 | 2164 |
| 165801 | +0.166 | 2052 |
| 170609 | +0.181 | 2015 |
| **均值** | **+0.185** | — |

**结论：三次实验符号一致为正，均值 r≈+0.18。雷达 X 确实携带横向位置信息，但相关性弱——绝对定位不可靠。**

分段分析（session 1）显示信号主要集中在预期阶段：

| 阶段 | r(X) | 解读 |
|------|------|------|
| slow_sweep | +0.447 | 慢速横向移动时追踪最强 |
| head_only | +0.228 | 转头产生 X 响应 |
| stand_sit | +0.229 | 站起/坐下伴随 X 变化 |
| still_30s | -0.218 | 静止期 X 漂移与头部位置反相关 |

**静止漂移是 X 不可靠的根源**：静止 30 秒内 X 漂移均值 128mm（σ），与缓慢人体移动幅度同量级。漂移源于 6.25mm 天线基线的相位干涉测角在多径环境下的相位中心游移。

### 3.2 LD2450 Y 轴：距离测量（MiDaS 验证结果不一）

MiDaS 深度 vs 雷达 Y 的 Pearson 相关（预期负相关）：

| 阶段 | S1 | S2 | S3 |
|------|------|------|------|
| fwd_back | **-0.534** | +0.015 | -0.208 |
| natural_typing | -0.533 | +0.138 | -0.066 |
| slow_sweep | -0.349 | -0.107 | -0.126 |
| ellipse | +0.374 | +0.472 | +0.324 |
| still_30s | -0.184 | -0.257 | +0.179 |

**S1 的前后移动阶段显示强负相关（-0.53），符合物理预期，但 S2/S3 未复现。** 可能原因：(a) MiDaS 相对深度在近距场景的尺度不稳定性；(b) 单目深度对坐姿人体躯干变化敏感而雷达 Y 测的是最近强反射体，两者物理量不完全同构。Y 通道在 phase-level 统计（Y_std：stand_sit 438mm vs head_only 51mm）上仍显示符合物理的响应模式，但其绝对数值与视觉深度的线性关系未获稳定验证。

### 3.3 LD2410C：Es 数值是姿态特征，Em 桌面场景无效，朝向感知不存在

**Es 数值（非二值存在）按行为系统性变化**（三次平均）：

| 行为 | Es 均值 |
|------|--------|
| natural_typing | 72.8 |
| head_only | 69.8 |
| still_30s | 63.9 |
| slow_sweep | 61.6 |
| quick_points | 59.1 |
| ellipse | 55.7 |
| fwd_back | 44.2 |
| stand_sit | 39.4 |

近 2 倍动态范围（39-73）。打字/只转头（上身稳定）时 Es 最高；站起坐下（身体形态剧变）时最低。**Es 数值可作为身体姿态的弱特征**，与 X/Y 联合供 TinyML 使用。

**Em 移动能量在桌面尺度基本失效**：三次平均触发率仅 2-6%（前倾后靠也只有 6%）。原因：LD2410C 出厂参数面向房间尺度（3-5m）设计，0.6-1m 近距离人体"太大、太近"，移动检测门控难以区分。

**Es 与头部朝向（MediaPipe head_yaw）相关系数三次均为 |r|<0.12**：LD2410C 在桌面场景**无法感知头部朝向**。"通过 Es 判断用户是否看向设备"的设计假设被实验证伪。

### 3.4 X 稳定性：移动优于静止的反直觉现象

跨三次平均的 X 标准差：

| 行为 | X σ (mm) |
|------|---------|
| stand_sit | 482 |
| slow_sweep | 218 |
| quick_points | 212 |
| ellipse | 158 |
| still_30s | 128 |
| natural_reach | 100 |
| natural_typing | 84 |
| fwd_back | 86 |
| head_only | 79 |

**持续运动（慢扫/快速定点）的 X σ 显著高于静止漂移基线（1.7x），说明运动信号可区分于漂移。** 但注意 still_30s 的 128mm 基线本身就是"噪声地板"，任何依赖 X 绝对值的单帧分类都不可行；只有时间窗口内的趋势模式（斜率、方差）才携带可用信息。

## 4. 讨论

### 4.1 对 TinyML 管线的影响

1. **可用特征收窄**：X 趋势（slope）、Y 距离、Es 数值、V（速度）四类信号有效；X 绝对值、Em、Es 朝向无效
2. **模型必须学到"何时信任 X"**：静止期 X 漂移与运动期 X 信号在单帧上不可分，但时间序列模式（持续同向 vs 随机游走）可被窗口特征捕获
3. **Es 数值升格**：从"存在检测器"升格为"姿态弱特征"，应纳入特征集并做消融实验验证贡献

### 4.2 与文献的一致性

- LD2450 静止目标检测不可靠、多径鬼影：与 ESPHome/Home Assistant 社区报告一致（esphome issue #9847 等）
- 24GHz 雷达 X 轴漂移的定量化（128mm/30s @0.7m）：本文贡献，未见公开数据
- 旋转敏感于平移的现象（head_only σ=79 vs still 漂移 128）：此前 session 曾观察到 head_only X 变化显著大于平移，本次未复现，标记为待进一步验证

### 4.3 局限

- n=1 被试，仅单一体型/坐姿
- MiDaS 单目深度为相对尺度，无法给出绝对距离验证
- 三次 session 时间跨度 ~1 小时，未覆盖跨日/跨光照条件
- 双雷达同频干扰未做 AB 对照（本次实验两雷达同时开启）

## 5. 结论

1. **LD2450 X 轴**：横向追踪信号真实存在（r≈+0.18，三 session 可重复）但被静止漂移（σ=128mm）淹没，仅趋势可用
2. **LD2450 Y 轴**：phase-level 统计符合物理预期；与单目深度的线性关系未获稳定验证，需双目/ToF 基准进一步确认
3. **LD2410C**：Es 数值是有效姿态特征（动态范围 ~2x），Em 桌面无效，头部朝向感知被证伪
4. **TinyML 路线**：以 X 趋势 + Y + Es 数值 + V 为特征集，时间窗口统计特征 + MLP 分类是合理路径；下一步应做 RF baseline 验证特征可分性
